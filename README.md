# Biology with Mahbub

A responsive bilingual (Bangla + English) biology learning website starter.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code with the Live Server extension.
3. No build tools or installation are required.

## Included
- Responsive homepage and navigation
- English/Bangla interface toggle
- Light/dark theme toggle
- Searchable biology dictionary with A–Z filtering
- Biology learning fields, article previews and study-resource section
- HTML, CSS and vanilla JavaScript

## Before publishing
- Replace the placeholder contact email `hello@biologywithmahbub.com` with your real email.
- Add your own original lessons, diagrams, PDFs and article pages.
- Update social links and connect a domain/hosting service.
- The current dictionary and article cards are starter content, not a complete encyclopedia.
